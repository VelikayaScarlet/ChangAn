This is the Readme.md for ChangAn. 

We provide all the code and data here. For data, we provide the original classical poetry created by humans (Classical Poetry.xlsx), and the test set file Test.xlsx. All the poems except seed poems are in the Untouched_Classical_Poetry.xlsx.

For Code, we provide the code of all models and methods. It is easy to run it after installing necessary packages and filling APIs.
